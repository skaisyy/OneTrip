# OneTrip — Website Prototype
Prototype website travel responsif dengan enam tahap alur pemesanan dan fitur tambahan.

## File
- `index.html` — struktur halaman dan konten.
- `styles.css` — desain responsif.
- `script.js` — navigasi dan interaksi prototype.

## Menjalankan
Buka `index.html` di browser. Bisa juga simpan folder ini di `htdocs` XAMPP lalu akses `http://localhost/onetrip-website/`.

## Push ke GitHub
Buat repository baru, lalu jalankan perintah ini dari terminal pada folder project:

```bash
git init
git add .
git commit -m "Create OneTrip travel website prototype"
git branch -M main
git remote add origin https://github.com/USERNAME/NAMA-REPOSITORY.git
git push -u origin main
```

Ganti USERNAME dan NAMA-REPOSITORY sesuai akun dan repository GitHub.

## Catatan
Foto memakai URL Unsplash dan font memakai Google Fonts, jadi perlu koneksi internet. Pembayaran dan data pemesanan masih simulasi front-end, belum terhubung database atau payment gateway. Kode promo demo: `TRAVEL25`.
